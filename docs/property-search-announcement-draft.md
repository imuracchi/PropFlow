# 物件募集機能 告知文（送信予定：2026年8月24日）

## メール・お知らせ

### 件名

【新機能】PropFlowで「探している物件」を募集できるようになりました

### 本文

PropFlowに、新しく「物件募集」機能が追加されました。

「このエリアで土地を探している」  
「買取再販向けの物件情報がほしい」  
「顧客の希望条件に合う物件を探したい」

このような購入・仕入れ希望条件を掲載し、他の不動産事業者から物件提案を受けられます。

### できること

- AIを使って、希望エリア、物件種別、予算、面積などの募集条件をかんたんに作成
- 会社名を公開せず匿名での募集
- 条件に合う掲載物件、未掲載物件の提案
- 提案後、そのままPropFlow内で商談

物件募集と提案を利用できるのは、名刺登録済みの認証ユーザーのみです。  
未認証の方は、マイページから名刺画像をご登録ください。

▼ 物件募集を見る  
https://propflow.jp/v2/property-search

## LINE・SNS用

PropFlowに「物件募集」機能が追加されました！

探している物件の条件を掲載し、不動産事業者から物件提案を受けられます。匿名募集にも対応しています。

募集・提案は名刺登録済みの認証ユーザー限定です。

https://propflow.jp/v2/property-search

アカウント・登録

新規登録の仕方を詳しく知りたい

物件掲載を含むすべての機能は、最初に新規登録とログインが必要です。

  1. 新規登録ページを開きます。
  2. 画面の案内に沿ってメールアドレスを確認し、氏名・会社名・パスワードなどの必須項目を入力します。
  3. 名刺を撮影または選択すると、氏名・会社名・電話番号などを自動入力でき、本人確認もスムーズです。
  4. 利用規約等を確認して登録を完了します。
  5. 登録したメールアドレスとパスワードでログインします。

登録に関するメールが見当たらない場合は、迷惑メールボックスに入っている可能性があります。受信トレイとあわせてご確認ください。

自分での登録が難しい場合は、下の「代理登録の具体的な手順」をご確認ください。

代理登録の具体的な手順を知りたい

メールアドレスが記載された、ご本人の名刺画像をご用意ください。入力作業をせず、次の手順で登録を依頼できます。

  1. 名刺を送って代理登録を開きます。
  2. 「名刺を撮影・選択」を押し、名刺を撮影するか保存済みの画像を選びます。JPEG・PNG・WebP形式、8MB以下の画像を利用できます。
  3. 読み取り結果が「名刺を確認できました」となったことを確認します。
  4. 利用規約・個人情報保護方針を確認し、ご本人の了承を得たうえで同意欄にチェックします。
  5. 「名刺を送信する」を押します。名刺記載のメールアドレスへ受付完了メールが届きます。
  6. PropFlow運営が名刺の内容を確認し、アカウントを代理登録します。
  7. ログインIDと初期パスワードを記載した登録完了メールが届いたら、その情報でログインしてください。

メールが届かない場合は迷惑メールフォルダをご確認ください。登録完了まで時間がかかる場合があります。

認証ユーザーとは？何ができますか？

認証ユーザーとは、登録した名刺をPropFlow運営が確認し、在籍情報などを確認できた利用者です。

認証されると、物件詳細・メッセージ・興味者リストなどに「認証済み」マークが表示され、相手が安心してやり取りするための目安になります。また、次の機能を利用できます。

  • 希望する物件条件を登録して、物件を募集する
  • ほかの利用者の物件募集に、条件に合う物件を提案する
  • DM画面から相手へ名刺情報を送る

認証を受けるには、ログイン後のマイページからご本人の名刺画像を登録してください。運営による確認後、認証済みマークが付与されます。代理登録で承認された場合も認証ユーザーとして登録されます。

なお、認証済みマークは名刺・登録情報を確認したことを示すもので、掲載物件の内容や取引の安全性を保証するものではありません。

ログインせずに物件を掲載できますか？

物件の掲載には、新規登録とログインが必要です。登録後にログインし、物件登録画面から所在地・価格・面積などを入力して公開してください。登録操作が難しい場合は、代理登録または下部の公式LINEへご相談ください。

ログイン方法・パスワードが分かりません
  1. ログインページを開き、登録したメールアドレスとパスワードを入力してください。
  2. パスワードを忘れた場合は、パスワード再設定ページに登録メールアドレスを入力します。
  3. 届いたメールのリンクから、新しいパスワードを設定してログインしてください。メールが見当たらない場合は、迷惑メールフォルダもご確認ください。

登録したメールアドレスも分からない場合や、再設定メールが届かない場合は、ご意見箱または下部の公式LINEから、氏名・会社名と状況をお知らせください。

登録メールが届かない・見当たらない
  1. 迷惑メール、プロモーション、ゴミ箱など、受信トレイ以外のフォルダを確認します。
  2. メールアプリで「PropFlow」と検索します。
  3. 新規登録時に入力したメールアドレスに、入力間違いがなかったか確認します。
  4. 会社のメールを使用している場合は、迷惑メール対策や受信制限によって拒否されていないか、社内のメール管理者へ確認します。
  5. 少し時間を置いてから、受信フォルダを再読み込みします。

それでも見つからない場合は、ご意見箱または下部の「LINEで質問する」から、氏名・会社名・登録したメールアドレス・登録したおおよその日時をお知らせください。パスワードは送らないでください。

マイページでは何ができますか？

マイページでは、自分の登録情報とPropFlowの各種設定を管理できます。

  • 氏名、会社名、資格・免許番号、住所、電話番号、FAX、URL、営業時間、定休日の確認・編集
  • 紹介資料へ使用する会社ロゴの登録・変更
  • 本人確認に使用する名刺の登録
  • 会社名の情報公開設定
  • 新着物件、物件募集、DMのメール通知設定
  • パスワードの変更
  • 削除した自社物件の確認・復元

画面のメニューから「マイページ」を開き、変更したい項目を選んでください。

紹介資料のロゴを自社のロゴにしたい
  1. メニューから「マイページ」を開きます。
  2. 「会社ロゴ」の「アップロード」を押します。登録済みの場合は「変更」を押します。
  3. 自社のロゴ画像を選択します。横長のPNGまたはJPG、2MB以下を推奨します。
  4. ロゴがマイページに表示されたことを確認します。
  5. その後、物件詳細の「紹介資料を作る」から新しくPDFを作成してください。

登録した会社ロゴは、物件の紹介資料をPDF出力するときに使用されます。すでに作成済みのPDFには自動反映されないため、ロゴ変更後に資料を作り直してください。

情報公開設定とは？

ほかの利用者に会社名を表示するか選ぶ設定です。マイページの「情報公開設定」で「会社名を表示する」のチェックを切り替えると、その場で保存されます。

氏名とメールアドレスは、サービス上の連絡や本人識別に必要なため公開必須です。また、チャットで「連絡先を送る」を押した場合は、この公開設定とは別に、登録している電話番号・FAX・URL・メールアドレスがその相手へ共有されます。

メール通知設定を変更したい

マイページの「メール通知設定」で、受け取りたい通知にチェックを入れます。チェックの変更はその場で保存されます。

  • 新着物件情報：新しい物件が登録されたときのお知らせ
  • 物件募集のお知らせ：前日に公開された募集を朝10時にまとめてお知らせ
  • DMが届いた：ダイレクトメッセージを受信したときのお知らせ

メールが届かない場合は、登録メールアドレスと迷惑メールボックスをご確認ください。

パスワードを変更したい
  1. メニューから「マイページ」を開きます。
  2. 「パスワード変更」を押して入力欄を開きます。
  3. 現在のパスワードを入力します。
  4. 新しいパスワードを8文字以上で入力し、確認欄にも同じ内容を入力します。
  5. 「パスワードを変更」を押します。

現在のパスワードが分からない場合は、ログイン画面のパスワード再設定をご利用ください。

「削除した物件」とは？復元できますか？

自社物件で「削除する」を押し、公開中の物件一覧から取り下げた物件です。削除後30日間は、マイページの「削除した物件」に表示され、ユーザー自身で復元できます。

  1. マイページの「削除した物件」を開きます。
  2. 戻したい物件の「復元」を押します。
  3. 必要に応じて「過去の商談相手へ再公開を知らせる」にチェックし、送信するメッセージを確認します。
  4. 「復元する」を押すと、物件が再公開されます。

削除から30日経過後は「削除した物件」から非表示になり、ユーザー画面からは復元できません。同時に、写真・添付ファイルだけを削除します。物件本体・物件概要・過去の商談履歴は、マーケティングデータとして活用するため、完全削除せず保持します。

物件を探す・募集する

物件を登録したいときは？

物件の登録には、PropFlowへの新規登録とログインが必要です。

  1. PropFlowへログインします。
  2. パソコンでは左側メニューの「物件を登録」を押します。スマホでは画面下部の「自社物件」を開き、「物件を登録する」を押します。
  3. 物件概要書のPDF・画像から入力する場合は、ファイルをアップロードして「AIで情報を抽出」を押します。自分で入力する場合は、手動入力を選びます。
  4. 物件名、所在地、価格、面積、物件種別、公開範囲、写真・添付資料などを入力します。
  5. AIを使用した場合も、元資料と照らし合わせてすべての項目を確認・修正します。
  6. すぐに掲載する場合は「今すぐ公開する」、あとで続きを入力する場合は「下書き保存する」を押します。

公開後は「自社物件」から登録内容を確認できます。AIの読み取り結果は内容を保証するものではありません。公開前に、登録者ご自身で入力内容・添付資料・公開範囲を必ずご確認ください。

物件を探すには？

物件一覧でエリアや物件種別などの条件を指定して検索できます。

希望する物件が見つかりません

希望物件を募集するから条件を公開すると、条件に合う物件を持つ利用者から提案を受けられます。

物件を募集したいときは？

物件募集を公開できるのは、名刺確認が完了した認証ユーザーです。未認証の場合は、先にマイページからご本人の名刺画像を登録してください。

  1. PropFlowへログインし、パソコンでは左側メニュー、スマホでは画面下部の「物件募集」を押します。
  2. 「物件を募集」を押します。
  3. 希望条件を文章で入力してAIで整理するか、「手動で入力」を選びます。
  4. 募集タイトル、希望エリア、物件種別、予算、面積、取得時期、その他の条件を入力・確認します。
  5. 募集者名を公開しない場合は、匿名設定を確認します。
  6. 内容を確認し、公開する場合は「募集を開始する」、あとで続きを入力する場合は「下書き保存」を押します。

募集を開始すると、条件に合う物件を持つ認証ユーザーから提案を受けられます。公開中の募集は1人5件までです。AIが整理した条件は内容を保証するものではないため、公開前に必ずすべての項目と公開内容をご確認ください。

物件募集への提案はどう行いますか？

物件募集一覧から条件に合う募集を開き、画面の案内に沿って物件を提案してください。提案後の確認はメッセージで行えます。

物件を削除したらどうなりますか？

「物件を削除する」は、物件を公開中の一覧から取り下げる操作です。

  • 物件一覧と物件詳細から非表示になり、新しい問い合わせを受け付けなくなります。
  • 削除後30日間は、マイページの「削除した物件」に表示され、写真・添付ファイルを含む状態で復元できます。
  • 30日経過後は「削除した物件」から非表示になり、ユーザー画面から復元できなくなります。同時に、写真・添付ファイルだけを削除します。
  • 物件本体・物件概要・過去の商談履歴は、マーケティングデータとして活用するため保持します。

削除操作と、物件が売れたことを記録する「成約報告」は別の機能です。成約した物件は削除ではなく「成約を報告」をご利用ください。

途中で物件を取り下げたいときは？
  1. ログイン後、メニューの「自社物件」を開きます。
  2. 取り下げたい物件を選び、物件詳細を開きます。
  3. 「物件管理」にある「物件を削除」を押します。
  4. 商談中の相手へ知らせる場合は、「やり取りした相手へのメッセージ」に取り下げ理由などを入力します。メッセージの入力は任意です。
  5. 確認画面の内容を確認し、「削除する」を押します。

操作後、物件は公開中の一覧から取り下げられます。戻す場合は、削除から30日以内にマイページの「削除した物件」から「復元」を押してください。成約により掲載を終了する場合は「物件を削除」ではなく「成約を報告」をご利用ください。

物件が成約したらどうすればよいですか？

物件を削除せず、「この物件を成約にする」から成約をご報告ください。

  1. ログイン後、メニューの「自社物件」を開きます。
  2. 成約した物件を選び、物件詳細を開きます。
  3. 「物件管理」にある「この物件を成約にする」を押します。
  4. 成約金額を入力します。金額が分からない場合は空欄でも登録できます。
  5. PropFlowの利用者全体へ知らせる場合は、「この成約を公式LINE・メールでPropFlow全体にお知らせする」にチェックします。
  6. 内容を確認し、「成約にする」を押します。

成約を登録すると、物件と商談画面に「成約済み」と表示され、その物件でやり取りしていた相手へ成約のお知らせが自動送信されます。過去の商談履歴は確認できますが、成約後はその物件について新しいメッセージや連絡先を送れません。

利用者全体への公式LINE・メール配信は任意です。チェックを入れた場合だけ配信されます。

商談・提案

個別物件について質問したい
  1. 物件一覧から質問したい物件を選び、物件詳細を開きます。
  2. パソコンでは画面右側、スマホでは画面下部の「問い合わせる」ボタンを押します。
  3. その物件専用のチャットが開くので、質問を入力して送信します。
  4. 掲載者から返信が届いたら、同じチャットで続きを確認・返信できます。

物件の条件、資料、交渉などの質問は、履歴を安全に残すため必ず対象物件の「問い合わせる」からお送りください。公式LINEでは個別物件の内容に回答していません。

個別物件の資料はどこで見られますか？
  1. 物件一覧から対象物件を選び、物件詳細を開きます。
  2. 画面を下へ進み、「関連資料」を確認します。
  3. 資料名を押すと内容をプレビューできます。右側の「DL」を押すと個別に保存できます。
  4. すべてまとめて保存する場合は「資料を一括ダウンロード」または「資料一括DL」を押します。

掲載者が公開している資料だけが表示されます。必要な資料が見当たらない場合は、その物件の「問い合わせる」から掲載者へご確認ください。

便利機能

お客様へ物件を提案する資料を作りたい

物件詳細の「紹介資料を作る」ボタンをご利用ください。

  1. お客様へ提案したい物件の詳細を開きます。
  2. 「物件ツール」にある「紹介資料を作る」を押します。
  3. 物件概要書、所在地地図、ストリートビュー、現場写真、交通アクセスなど、PDFに含めるページを選びます。
  4. 必要に応じて、掲載者が公開している添付資料も選びます。
  5. 紹介資料を作成し、完成したPDFを確認・ダウンロードします。

自社の会社名・ロゴなどを反映した、お客様へ渡しやすい紹介資料を作成できます。作成済み資料はメニューの「ダウンロード資料」からも確認できます。

利益シミュレーションの使い方を知りたい
  1. 試算したい物件の詳細を開き、「物件ツール」の「利益を試算する」を押します。
  2. 土地代金、建築費、諸費用などを「原価明細」に入力します。仲介手数料の計算条件も変更できます。
  3. 「1坪あたり単価」と「坪数」を入力します。
  4. 画面に自動表示される原価合計、売買価格、利益、利益率を確認します。
  5. 保存・共有する場合は「PDFダウンロード」を押します。作成したPDFは「ダウンロード資料」からも確認できます。

シミュレーション結果は入力値に基づく概算です。実際の費用・税金・取引条件を確認したうえでご利用ください。

お気に入り機能の使い方を知りたい
  1. 保存したい物件の詳細を開き、ハートマークの「お気に入り」または「お気に入りに入れる」を押します。
  2. 登録後は表示が「お気に入り済み」に変わります。
  3. 保存した物件は、メニューの「お気に入り」からまとめて確認・比較できます。
  4. 解除する場合は、対象物件の「お気に入り済み」をもう一度押します。

お気に入りは自分の検討物件を整理するための機能です。お気に入りに入れただけでは、掲載者への問い合わせは送信されません。

閲覧制限機能とは？設定方法を知りたい

閲覧制限は、自分が登録した物件を、指定した利用者に表示しないための機能です。物件ごとに設定でき、利用者自体をPropFlow全体からブロックする機能ではありません。

設定された利用者には、その物件が物件一覧・物件詳細のどちらにも表示されず、関連資料も閲覧・ダウンロードできません。すでにその物件でチャットしていた場合は過去の商談履歴だけ確認でき、新しいメッセージは送信できなくなります。新着メールやプッシュ通知の送信対象からも除外されます。

  1. メニューの「自社物件」から対象物件を開きます。
  2. 物件詳細の「物件管理」にある「閲覧制限を設定」を押します。
  3. 「名前・会社名で検索」に、制限したい利用者の氏名または会社名を入力します。
  4. 検索結果から対象者を選ぶと、その物件の閲覧制限へ追加されます。

解除する場合は、同じ「閲覧制限を設定」を開き、制限中の利用者の右側にある「×」を押します。物件の新規登録時にも閲覧制限を設定できます。

閲覧制限を設定した物件は、情報保護のため公式LINEでの新着配信を行いません。

AIを使って物件を登録するには？

物件概要書のPDFまたは画像をAIで読み取り、物件情報の入力を補助できます。

  1. メニューから「物件を登録」を開きます。
  2. 物件概要が分かるPDFまたは画像をアップロードします。精度を保つため、まずは概要がまとまった1ファイルの利用をおすすめします。
  3. 「AIで情報を抽出」を押し、解析が終わるまで待ちます。
  4. 「内容確認・編集」画面で、所在地・価格・面積・物件種別・公開範囲・添付資料など、すべての項目を元資料と照らし合わせて確認・修正します。
  5. 内容と公開範囲に問題がないことを確認してから、「今すぐ公開する」または「下書き保存する」を押します。

AIの読み取り結果は入力を補助するための下書きであり、正確性や完全性を保証するものではありません。誤読・未入力・異なる数値が含まれる可能性があります。公開ボタンを押す前に、必ず登録者ご自身で全項目と資料を確認してください。

AIを使って物件募集を登録するには？

探している物件の条件を文章で入力すると、AIが募集項目ごとに整理します。

  1. 「物件募集」から「物件を募集する」を押します。
  2. 希望エリア、物件種別、予算、面積、取得時期などを、できるだけ具体的な文章で入力します。
  3. 「AIで条件を整理」を押します。AIを使わない場合は「手動で入力」を選べます。
  4. 「条件を確認・編集」画面で、募集タイトル・希望エリア・物件種別・価格・面積・匿名設定など、すべての項目を確認・修正します。
  5. 個人名、電話番号、メールアドレスなど公開したくない情報が文章に残っていないことも確認します。
  6. 内容に問題がないことを確認してから、「募集を開始する」を押します。不安がある場合は「下書き保存」を利用してください。

AIが整理した条件は内容を保証するものではありません。条件の取り違えや抜けが生じる可能性があるため、「募集を開始する」を押す前に、必ず登録者ご自身で全項目と公開内容を確認してください。

メッセージ・通知

スマホで画面通知を受け取りたい

スマホの画面に表示される通知は「プッシュ通知」です。PropFlowをホーム画面に追加し、通知を許可すると、新着物件やDMなどの通知を受け取れます。

iPhoneの場合

  1. SafariでPropFlowを開き、ログインします。
  2. 画面下部の共有ボタン（□に↑）を押します。
  3. 「ホーム画面に追加」→「追加」を押します。
  4. ホーム画面に追加されたPropFlowのアイコンから開き、ログインします。
  5. 通知の確認が表示されたら「許可」を押します。

Androidの場合

  1. ChromeでPropFlowを開き、ログインします。
  2. 表示される「インストール」または右上の「︙」→「アプリをインストール」を押します。
  3. ホーム画面に追加されたPropFlowのアイコンから開きます。
  4. 通知の確認が表示されたら「許可」を押します。

以前「許可しない」を選んだ場合は、スマホの設定からPropFlowまたは使用しているブラウザの通知をオンにしてください。通知を許可していても、閲覧制限が設定された物件など、配信対象外の情報は通知されません。

公式LINEに新着物件が届かないときは？

新着物件のLINE配信を受け取るために、PropFlowのアカウントとLINEを連携する操作は必要ありません。まず、PropFlow公式LINEを友だち追加しているかご確認ください。

  1. LINEでPropFlow公式アカウントのトーク画面を開きます。
  2. 公式アカウントをブロックしている場合は、ブロックを解除します。
  3. トーク画面右上のメニューから「通知」がオンになっているか確認します。通知がオフの場合でも、配信済みの新着情報はトーク画面で確認できます。

すべての登録物件が公式LINEへ配信されるわけではありません。掲載者が新着通知を送信しなかった物件、特定の相手だけに提案した物件、閲覧制限を設定した物件は、公式LINEへ新着配信されません。

上記を確認しても公式LINEの配信が一度も届かない場合は、下部の「LINEで質問する」から状況をお知らせください。

「お知らせ」とは？

PropFlow運営から配信された案内を、サービス内で確認するための機能です。運営からのご案内や、PropFlow全体へ配信された成約情報などが掲載されます。

  1. ログイン後、画面上部またはメニューにあるベルマークの「お知らせ」を押します。
  2. 未読のお知らせがある場合は、「お知らせ」に未読件数が表示されます。
  3. 確認したい件名を押すと、本文や画像を確認できます。開いたお知らせは既読になります。

「お知らせ」は、個別物件について掲載者とやり取りする物件チャットやDMとは別の機能です。個別物件への質問・交渉は、対象物件の「問い合わせる」からお送りください。

メールや公式LINEでも同じ案内を配信する場合がありますが、PropFlow内だけに掲載されるお知らせもあります。

問い合わせ・提案

問い合わせ後に物件が成約・削除された場合は？

成約した場合

  • 掲載者が物件を「成約」にすると、問い合わせのあった方へチャットで成約のお知らせが届きます。DMのメール通知を有効にしている場合は、メールでも通知されます。
  • 物件とチャットに「成約済み」と表示されます。
  • 過去のメッセージは確認できますが、その物件について新しいメッセージや連絡先を送ることはできません。

削除された場合

  • 物件一覧・物件詳細から表示されなくなり、写真・関連資料も閲覧やダウンロードができなくなります。
  • 掲載者が削除時にメッセージを入力した場合は、問い合わせのあった方へ削除前にそのメッセージが届きます。メッセージの入力は任意のため、通知がない場合もあります。
  • チャットには「この物件は削除されました」と表示され、過去の問い合わせ履歴だけ確認できます。新しいメッセージや連絡先は送れません。掲載者が物件を復元すると、物件一覧・詳細へ再公開できます。

検討に必要な資料や重要なメッセージ内容は、物件が成約・削除される前にご自身で保存してください。成約・削除後の資料提供や連絡の継続が必要な場合は、事前に共有された連絡先から相手へご確認ください。

「連絡先を送る」「相手の連絡先」はどう使いますか？

物件のチャットで、チャット相手と電話番号などを共有するための機能です。チャットを開始しただけでは、お互いの連絡先は自動的に公開されません。

自分の連絡先を送る場合

  1. 対象物件のチャットを開き、メッセージ入力欄の上にある「連絡先を送る」を押します。
  2. 共有される電話番号・FAX・URL・メールアドレスを確認します。
  3. 名刺を登録している場合は、「名刺も合わせて送る」を選択できます。さらに「物件資料リンクも送る」を選べます。
  4. 「連絡先を共有」を押すと、そのチャットの相手へ送信されます。

相手の連絡先を見る場合

  1. 同じチャット内の「相手の連絡先」を押します。
  2. 相手が連絡先を共有済みの場合、電話番号・FAX・URL・メールアドレスなどが表示され、必要な項目をコピーできます。
  3. 相手がまだ共有していない場合は「相手はまだ連絡先を共有していません」と表示されます。チャットで共有をお願いしてください。

連絡先の共有は一方向です。自分が送っても、相手の連絡先が自動的に見えるようにはなりません。相手からも「連絡先を送る」を行ってもらう必要があります。

送信前に、マイページへ登録している連絡先が最新か、送る相手と物件に間違いがないか必ず確認してください。成約済みの物件や閲覧制限中の物件では、連絡先を送信できません。

届いたメッセージはどこで確認できますか？

ログイン後のメッセージ一覧から確認できます。物件に関する会話は、対象物件のチャットからも開けます。

LINEのトークで物件交渉できますか？

公式LINEはサービス案内と通知・操作サポート用です。物件の質問や交渉は、履歴を安全に残せるPropFlow内の物件チャットをご利用ください。

不動産の情報収集へのご意見箱からお送りください。ログインしていなくても投稿できます。

利用者間でトラブルが起きた場合、運営は対応しますか？

PropFlowは不動産情報の共有と連絡を支援するプラットフォームであり、不動産取引の売主・買主・仲介者・代理人・契約当事者ではありません。

物件情報の確認、連絡、交渉、契約および取引は、利用者ご自身の判断と責任で行ってください。利用者間または利用者と第三者との間で生じた紛争、苦情、請求、損害その他のトラブルについて、運営は解決・仲介する義務を負わず、当事者間の費用と責任で解決していただきます。

物件情報の正確性・最新性、契約の成立・履行・成果についても運営は保証しません。重要事項や相手方の資格・権限は、契約前に必ずご自身で確認してください。

迷惑行為、不正利用、虚偽情報など利用規約に違反する可能性がある行為を見つけた場合は、証拠となる画面やメッセージを保存し、下部の公式LINEへご報告ください。緊急性や違法性が疑われる場合は、警察・弁護士など適切な専門機関へご相談ください。

詳しくは利用規約（特に免責事項）をご確認ください。

PropFlowをご利用になる前に、利用規約と個人情報保護方針を必ずご確認ください。禁止事項、掲載情報や取引に関する責任、登録情報・個人情報の取り扱いなどを定めています。内容をご理解・同意いただいたうえでサービスをご利用ください。

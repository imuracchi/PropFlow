PropFlow EASY GUIDE

かんたん使い方ガイド

パソコンでもスマホでも使えます。やりたいことを選び、実際の画面を見ながら番号順に操作してください。

1物件を探したい2問い合わせたい3資料などを送りたい4希望物件を募集したい
1

物件を探す

  1. 「物件一覧」を開きます。
  2. 地域を選び、必要なら「詳細条件」を押します。
  3. 気になる物件名を押して、詳しい内容を確認します。
  4. あとで見たい物件はハートの「お気に入り」へ入れます。
迷ったときは、まず地域だけ選んで探すのがおすすめです。
2

物件について問い合わせる

  1. 物件一覧から、確認したい物件を開きます。
  2. 価格・物件概要・関連資料を確認します。
  3. 「問い合わせる」を押します。
  4. 質問を入力して送信します。返信も同じ画面で確認できます。
資料が見当たらない場合も、問い合わせから掲載者へ確認できます。
3

資料や連絡先を共有する

  1. 対象物件の問い合わせ画面を開きます。
  2. 「共有する」を押します。
  3. 連絡先・名刺・物件資料から、送りたいものを選びます。
  4. 相手と内容を確認して共有します。
非表示資料を選んでも一般公開されません。選んだ相手にだけ送られます。
4

希望する物件を募集する

  1. 「物件募集一覧」を開きます。
  2. 「物件を募集」を押します。
  3. 希望する地域・物件種別・予算などを入力します。
  4. 内容を確認して募集を開始します。
文章をAIで整理する方法と、自分で項目を入力する方法を選べます。

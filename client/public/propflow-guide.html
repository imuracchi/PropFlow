買う側

物件を探す・問い合わせる

1

物件を探す

買う側
  1. 「物件一覧」を開きます。
  2. 地域を選び、必要なら「詳細条件」を押します。
  3. 気になる物件名を押して、詳しい内容を確認します。
  4. あとで見たい物件はハートの「お気に入り」へ入れます。
迷ったときは、まず地域だけ選んで探すのがおすすめです。
2

物件について問い合わせる

買う側
  1. 物件一覧から、確認したい物件を開きます。
  2. 価格・物件概要・関連資料を確認します。
  3. 「問い合わせる」を押します。
  4. 質問を入力して送信します。返信も同じ画面で確認できます。
資料が見当たらない場合も、問い合わせから掲載者へ確認できます。
3

希望する物件を募集する

買う側
  1. 「物件募集一覧」を開きます。
  2. 「物件を募集」を押します。
  3. 希望する地域・物件種別・予算などを入力します。
  4. 内容を確認して募集を開始します。
文章をAIで整理する方法と、自分で項目を入力する方法を選べます。
売る側

物件を掲載する・資料を送る

1

物件を掲載する

売る側
  1. メニューの「物件を登録」を開きます。
  2. 販売図面などの資料を選ぶと、AIが物件情報を読み取ります。
  3. 読み取った内容と、添付資料の公開・非公開を確認します。
  4. 「今すぐ公開」または「一時保存」を選びます。
最初からすべて入力しなくても、PDFや画像を読み取って登録できます。公開日時の予約も可能です。
2

資料や連絡先を送る

売る側
  1. 問い合わせが届いた物件のDMを開きます。
  2. 「共有する」を押します。
  3. 連絡先・名刺・物件資料から、送りたいものを選びます。
  4. 内容を確認して相手へ共有します。
非表示資料も選択できます。一般公開はされず、選んだ相手にだけ送られます。
